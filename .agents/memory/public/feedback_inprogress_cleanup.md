# In-Progress Status & Interstitial Message Ban

**All in-progress messages, starting announcements, and interstitial status posts are PERMANENTLY DISABLED.** (Ratified 2026-09-21: *"I never want those interstitial messages to show up. You just deliver the result when you're done."*).

### Rules for All Execution (Main Turns, Sidecars, Background Workers):
1. **No Starting Announcements:** Never send a starting message (`Starting execution...`, `Running sidecar...`, `On it`).
2. **No Interim Milestone Edits:** Do not post placeholder messages or edit spinners during execution.
3. **Single Finished Delivery:** Deliver strictly the final output, report, or findings when execution is 100% complete.
4. **Scheduled Silence:** Scheduled sidecars run completely silently in the background and only post if there are substantive findings to report (or remain 100% silent when nominal).
