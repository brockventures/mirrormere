Ryan asked 2026-08-10 whether Claude Pro ($20/mo) was worth it given how much Ivy uses it (continuous background agents, scheduled timers, Discord harness) vs. ChatGPT/Codex CLI and Gemini as alternatives. Researched current state of all three.

**The load-bearing fact: Anthropic's Agent SDK usage split was announced, then paused the same day it was supposed to take effect (2026-06-15), and never actually shipped.** The plan was to move "Agent SDK / headless (`claude -p`) / GitHub Actions / third-party-app" usage — exactly Ivy's usage pattern — off the normal chat subscription pool onto separate metered credits. It didn't happen. As of this writing, Ivy's background-agent spawning and scheduled jobs all still ride the flat $20/mo Pro pool, same as normal chat usage. This is why the $20/mo feels disproportionate to actual usage — Ivy is using it far harder than a typical subscriber, at the same price. **Anthropic said they'd give notice before re-attempting the split — watch for that announcement, since it would directly change Ivy's real operating cost.**

**Real measured number, computed 2026-08-10 (not an estimate) — corrects the $200-500/mo figure below, which was too LOW:** parsed all 561 local session JSONL transcripts (`~/.claude/projects/-home-droid-projects/*.jsonl`, 106MB, transcripts only go back to 2026-07-10) for the trailing 30 days. After deduplicating resumed/forked sessions (17,643 raw records → 7,463 unique `message.id`s, a 2.4x overcount if not handled) and taking max `output_tokens` per id (streaming partials re-write the same id), actual metered-API-equivalent cost is **$875.58** (standard pricing) or **$632.30** (Sonnet 5's intro pricing through 2026-08-31) — **~44x the $20/mo Pro price**. Breakdown: 1.36B cache-read tokens (0.1x rate, $433.44, 49.5% of cost) + 53.4M cache-write-1h tokens (**2x base rate, not 1.25x** — Claude Code uses 1-hour cache TTL, this is 38.5% of the bill on its own) + 5.2M output tokens ($91.68) + minor 5m-cache-write and base-input. By model: Sonnet 5 $729.86, Opus 5 $123.14, Opus 4.8 $22.54, Haiku negligible. **96% of all tokens are cheap cache reads, but the raw volume (1.36 billion) is so large it dominates the bill anyway** — cheap-per-token doesn't mean cheap-in-aggregate at this usage scale. Script preserved at `/tmp/claude-1000/-home-droid-projects/e9f23133-f230-464b-920b-6f8633488448/scratchpad/cost_audit2.py` (session-scratchpad, may not persist — rewrite from this description if needed again). **This makes the paused Agent-SDK metering split (above) a much bigger deal than "watch for it" — if it ships, the realistic cost cliff is ~$850+/mo, not a minor bump.**

**Superseded generic estimate (kept for context only, real number above is authoritative):**
- Pure metered Claude API instead of Pro: ~$200-500/mo for a workload like Ivy's (Sonnet $3/$15 per MTok, Opus $5/$25 per MTok as of this research) — strictly worse than staying on Pro or even upgrading to Max.
- Max tier: $100/mo (5x) or $200/mo (20x) — the real upgrade path if Ryan ever actually hits rate-limit walls (not just a value feeling). Pro + "usage credits" enabled is a cheaper hedge (overflow to API rates only after the plan pool exhausts) before jumping straight to Max.
- ChatGPT: Codex CLI is now a legitimate peer to Claude Code (open source, real headless/cron mode via `codex exec`, multi-agent support stabilized v0.145.0 2026-07-21). Realistic cost ~$100-200/mo (Pro tier) for equivalent usage — not cheaper than Ivy's current setup.
- **Gemini CLI is dead** — Google stopped serving it to free/Pro/Ultra accounts 2026-06-18, replaced by a closed-source Go binary called Antigravity (`agy`). The exact tool the old Gemini Ivy (see [[project_gemini_migration]]) was built on no longer exists. Antigravity has documented ongoing stability complaints into 2026 (long hangs, encoding corruption) — reconsidering Gemini now means rebuilding on a different, closed-source tool with unresolved reliability concerns, not reviving the old setup.

**Recommendation given: stay on Claude Pro $20/mo.** Best available deal right now, both alternatives are worse-value or the specific tool no longer exists. Don't preemptively upgrade to Max without an actual rate-limit wall being hit.

**Why cache usage is so high, broken down 2026-08-10:** Ryan asked what's actually driving 1.37B cache-read / 56M cache-write tokens. Extended the same 30-day dataset (script: `cache_breakdown.py`, same scratchpad as above, may not persist). Findings:
- **Cache writes happen on almost every call** (7,485 of 7,487) but are typically tiny (median 1,247 tokens) — normal incremental "add this turn" behavior. A handful are enormous (top 10: 740K-895K tokens each) — these correspond to huge single-shot content landing in context (large fetched webpages, log dumps, PDF/HTML tool results) in one turn.
- **Cache reads dominate because every API call in a running conversation must re-process the entire conversation-so-far as input** — there's no way to send only "the new part." Average read per call: ~218,000 tokens. This is structural to how LLM context windows work, not inefficiency.
- **568 distinct session files touched in 30 days** (~19 new agent spawns/day) — matches heavy background-agent-spawning activity. One single session (the main persistent Discord session, which stays alive for days without restarting) had **1,195 turns** — the longer any one conversation runs, the more expensive every subsequent turn in it gets, even though each turn is individually cheap via caching.
- **Bottom line given to Ryan:** not waste, it's the real cost structure of "one agent, always on, doing continuous multi-step work, staying in the same conversation for days." The only lever to reduce it would be restarting the main session more often to cap conversation length (trades cost for continuity) — moot right now since he's on flat $20/mo regardless.

**Wider field survey (DeepSeek + flat-rate alternatives), researched 2026-08-10.** Ryan asked whether any flat-rate or dramatically-cheaper option exists industry-wide beyond Claude/OpenAI/Gemini.
- **DeepSeek: no subscription, API-only, but genuinely notable** — ships an Anthropic-compatible endpoint (`https://api.deepseek.com/anthropic`) and explicitly documents Claude Code as a supported client. Swapping `ANTHROPIC_BASE_URL`/`ANTHROPIC_AUTH_TOKEN` would run Ivy's whole harness unchanged, no rewrite — unlike the Gemini migration which needed all-new tooling. Cost vs. the measured $876/mo Claude-metered baseline: ~$25-40/mo on DeepSeek V4-Flash, ~$75-110/mo on V4-Pro (8-40x cheaper). Real caveats: DeepSeek's own docs warn of an imminent "significant" price increase (today's numbers not durable); independent tool-call evals show real agentic reliability gaps (~35-40% missing/wrong tool calls on V3.2, better but unproven at Ivy's 24/7 multi-agent scale on V4) — failure mode would be silent wrong actions against HA/Gmail, not just a bad reply; and it's Chinese-company/PRC-hosted infrastructure, a real factor given what Ivy has access to (home automation, email, calendar).
- **Bigger find: a tier of genuinely flat-rate coding plans also compatible with Claude Code via the same Anthropic-endpoint trick** — Z.ai GLM Coding Plan ($18-160/mo), Kimi Code/Moonshot ($19-199/mo), cheaper still: MiniMax (~$10+), StepFun (~$7+), Xiaomi MiMo (~$6+). Real subscriptions, not metered. Catch: quotas are prompts-per-5-hours; Ivy's always-on multi-agent pattern would likely need the $72-160 tiers, not the cheap ones. Same China-provider caveat applies to most.
- **Ruled out:** GitHub Copilot went metered mid-2026 (Max $100/mo ≈ $200 credits), and its agent is repo/PR-shaped, not a general assistant harness anyway. Cursor's "flat" tiers are just credit pools, still metered underneath. Self-hosting is dead on arrival — rented GPU compute runs $1,000-16,000/mo depending on model size, worse than metered Claude.
- **Recommendation given:** stay on Claude Pro, nothing beats $20 flat at this capability level right now. Real hedge worth doing eventually (not urgent): since Ivy's harness is Anthropic-API-compatible by design, swapping the *backend* provider (not rebuilding the harness) is a fast, low-effort escape hatch if the paused Agent SDK metering split ever actually ships — worth proving out on a scoped/no-real-credentials test instance sometime, as insurance.

**How to apply:** If Ryan asks about this again, or if Ivy starts hitting rate limits / degraded service that could indicate metering changed, check whether Anthropic has re-announced the Agent SDK credit split before assuming it's just normal usage variance — that's the specific event that would change this cost analysis.
