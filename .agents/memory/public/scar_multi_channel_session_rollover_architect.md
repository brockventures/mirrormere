Confirmed 30-day brain pruning is safe for dreaming memory consolidation, but revealed the 2:00 AM session rollover is broken for multi-channel setups because it hardcodes channel names (e.g. "home") and ignores active Crab Cavern daemon channels (`#the-banana-stand`, `#lounge`, `#zero-ops`). Consequently, unhandled channels fail to roll over daily and accumulate turns until hitting compaction limits.
