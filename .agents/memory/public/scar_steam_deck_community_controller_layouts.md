Steam strictly keys non-Steam Community Controller Layouts by the exact game title string on the shortcut. To surface layouts like `EverQuest Legends - StackTrace - v1.3`, the Deck shortcut must be renamed exactly to `EverQuest Legends` rather than shorthand variants like `EQLegends`.
